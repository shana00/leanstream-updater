# LeanStream Updater1.1.10

Cumulative updater: update directly from an older updater, without intermediate
updater releases. After a normal Kodi exit/reopen, select Check Shield test release
for one complete private add-on + skin + AI installation. Older suite releases
do not need to be installed first. The public ZIP contains only the updater.

After a verified completed paired-suite installation, startup automatically
applies the PC scraping policy ONCE, with a preference-only restore backup:
15 qualifying cached torrent source target,10-second timeout, tier skip off,
plus the remaining nine recorded PC scrape rules. Cloud/direct/adaptive rules
can stop before15. This is not15 guaranteed playable links;10s can omit slow
providers. No new providers or account credentials are installed or copied.

Existing complete/declined/restored/failed scraping records and later personal
choices are preserved. Restore PC scraping preferences remains separate from
code restore. With an existing valid paired-suite receipt, upgrading the updater
alone can perform this once on restart; no previous updater release is required.
Without a receipt, the full suite installation creates one. Busy playback/other
dialogs defer setup; interrupted transactions require restore, not an auto reset.

Setup check reports installed suite roots, recursive Kodi dependencies, AI files
and settings, provider metadata presence and saved service configuration. It does
NOT validate credentials online, remaining quota, title ratings or playback.
No login, sync, install or credential/settings write occurs. Inventory makes no
network requests. Optional QR sharing starts a temporary private-LAN HTTP server
only while the QR is open (maximum five minutes). Trusted same-Wi-Fi only; HTTP
is not encrypted. No external QR service or automatic public upload/email.
QR downloads the complete sanitized report, not just the six-row checklist.
Save report writes only that text to a user-chosen folder with a unique name.
Raw Kodi logs, keys, tokens, account values and playback URLs are NOT included.
New suite Accounts > Setup check invokes a fixed read-only updater action.
Optional modules are not required blockers. Built-in Kodi interfaces are part of
Kodi, not separate downloads. Playback accounts are alternatives, not all required.
MDBList extra rating key is separate from watch/list enablement. Connect your own
services privately. Never send token values, keys or account settings screenshots.

Trailer/Android presets remain optional, require confirmation and are NEVER applied by
Setup check. Android preset: MediaCodec ON / Surface OFF and maximum1080p trailers.
ALL Kodi video is affected; HDR/Dolby Vision OUTPUT remains unverified. Read full
scrollable details before deciding. Automatic scraping changes only12 allowlisted
scraping values, not Android decoder/display/HDR/YouTube/account settings.

Preference backup/readback/rollback/restore is separate from CODE restoration.
Restore interrupted changes first; newer choices and changed schemas/versions are
not overwritten. No boot-time enforcement. A valid completed paired-suite receipt
is required for one-time automatic scraping; trailer consent is independent.

Install the verified local ZIP without uninstalling or clearing data; exit/reopen
Kodi normally. Each device keeps its own credentials. Use the private TEST channel;
stable remains unchanged. HDR/Dolby output/colours and intermittent freezes are
separate open gates, not fixes claimed by this package.
