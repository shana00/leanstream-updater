# LeanStream updater1.1.12

Compatibility bridge for existing Kodi21 updater clients. Restart Kodi normally after installation, then use Update updater again for the pinned signed core1.2.2. Restart Kodi normally again after the core installs. Missing, disabled or old Crypto stops before core installation.

Updater code only. Private suite, skin, AI, accounts and tokens are not included. No signed friend content job is available; do not use Update LeanStream. Enrollment and revoke remain local to the device.
